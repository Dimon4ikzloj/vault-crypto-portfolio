# Vault — крипто-портфель на Google Sheets

Веб-приложение на **Google Apps Script** + **Google Таблица**: учёт сделок, цены с CoinMarketCap, аллокация, график инвестирования, TradingView по монетам.

У каждого пользователя **своя** таблица, **свой** API-ключ и **своё** развёртывание — данные не пересекаются.

---

## Что нужно

- Аккаунт Google
- Бесплатный API-ключ [CoinMarketCap](https://coinmarketcap.com/api/) (план Basic достаточно)
- ~15 минут на первую настройку

---

## Быстрый старт

### 1. Google Таблица

1. Создайте новую [Google Таблицу](https://sheets.google.com) — пустую, без каких-либо действий внутри неё. Больше ничего в самой таблице руками делать не нужно.

   При первом открытии веб-приложения скрипт **сам** найдёт или создаст лист **«Сделки»** и сам добавит правильную строку заголовков с оформлением — ручное создание листа/заголовков не требуется.

   <details>
   <summary>Как выглядит автоматически создаваемая структура (справочно)</summary>

   Скрипт читает данные по номеру колонки, а не по названию заголовка, поэтому порядок всегда такой:

   | ID | Тип | Монета | Количество | Цена | Сумма | Комиссия | Дата | P&L | Средняя цена покупки | Примечания |
   |----|-----|--------|------------|------|-------|----------|------|-----|----------------------|------------|

   **Тип:** `Покупка` · `Продажа` · `Аирдроп` · `Скам`

   Если хотите завести лист руками заранее (необязательно) — назовите его **`Сделки`** и используйте именно этот порядок колонок.
   </details>

### 2. Apps Script

1. В таблице: **Расширения → Apps Script**.
2. Удалите содержимое файла `Code.gs` по умолчанию.
3. Скопируйте из этого репозитория:
   - `Code.gs`
   - `index.html` (в редакторе: **+** → **HTML** → имя `index`)
4. В **`Code.gs`** в начале файла замените:

   ```javascript
   const API_KEY = "YOUR_API_KEY";
   ```

   на свой ключ CMC.

### 3. Разрешения (один раз)

В редакторе Apps Script выберите функцию и нажмите **▶ Выполнить** для каждой:

| Функция | Зачем |
|---------|--------|
| `authorizeExternalRequests` | Доступ к CoinMarketCap |
| `setupAutoUpdate` | Фоновое обновление цен (триггер каждый час, API — раз в 4 ч.) |

Подтвердите **Разрешить** в окне Google.

### 4. Развёртывание веб-приложения

1. **Развернуть → Новое развёртывание**
2. Тип: **Веб-приложение**
3. **Выполнять от имени:** «Я»
4. **У кого есть доступ:** «Только я» (или «Все, у кого есть аккаунт Google» — если делитесь ссылкой только с друзьями)
5. **Развернуть** → скопируйте **URL**

Это **ваша** личная ссылка на портфель.

### 5. Первая синхронизация

Откройте URL → **⟳ Синхронизировать**. Цены подтянутся с CMC (не чаще раза в 4 часа на ключ).

## Как поделиться с друзьями

**Не** давайте свой URL и **не** коммитьте API-ключ в Git.

Каждый человек:

1. Делает **fork** / **clone** этого репозитория (или скачивает ZIP).
2. Повторяет шаги **Быстрый старт** со **своей** таблицей и **своим** ключом CMC.
3. Получает **свой** URL развёртывания.

Так у всех отдельные сделки, настройки TradingView и лимиты API.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `Code.gs` | Backend: таблица, CMC API, кэш, триггеры |
| `index.html` | UI: портфель, графики, сделки |

Данные хранятся в **вашей** Google Таблице (лист «Сделки»). Скрипт может быть привязан к таблице или использовать `SPREADSHEET_ID` в **Свойствах проекта** (Apps Script → ⚙ → Свойства скрипта).

## Частые вопросы

**Нет цены для монеты**  
Добавьте UCID с CoinMarketCap (число из URL монеты) в «Трекер активов» или укажите тикер, если он однозначный.

**Фоновая синхронизация не работает**  
Запустите `setupAutoUpdate()` в редакторе Apps Script. Из браузера триггер создать нельзя — это ограничение Google.

**TradingView: ошибка 403 по биржам**  
На тарифе CMC Basic недоступен endpoint market-pairs — графики работают через резервные символы и ручные настройки биржи.

**Обновил код**  
Apps Script → **Развернуть → Управление развёртываниями → ✏ → Новая версия**.

## Безопасность

- **Никогда** не публикуйте `Code.gs` с реальным API-ключом.
- Если ключ попал в git или чат — **перевыпустите** его в кабинете CoinMarketCap.
- URL веб-приложения с доступом «Все» открывает **ваш** портфель — для личного учёта лучше «Только я».
